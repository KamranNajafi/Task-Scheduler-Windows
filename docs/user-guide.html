Privileged Application Delegation for Windows

An administrator lets a standard (non-admin) user run specific approved applications with administrator rights — without sharing the admin password.

English

1. What it is

Task Delegator lets an administrator allow a standard (non-admin) user to run specific, approved applications with administrator rights — without giving out the administrator password. It is ideal for a training lab / classroom: students can launch software that requires admin rights, but cannot uninstall it or change anything.

2. Install

  1. Run TaskDelegatorSetup.exe and approve the UAC prompt.
  2. It installs to Program Files and adds shortcuts: Allowed Programs (for everyone) and Task Delegator (Administrator).
No prerequisites. The installer uses the .NET Framework 4.8 that is built into Windows 10/11 — nothing else to install.

3. Administrator — create a delegation

  1. Open Task Delegator (Administrator) (or run the app and click Administrator…) and approve UAC. This is the "admin login".
  2. On the Create delegation tab:
    • Installed application — pick it from the list (type to filter), or Browse… to its .exe.
    • Target Windows user — pick the user (works for Standard users).
    • Run as — SYSTEM (no password) is recommended; or choose Admin account and type an administrator account + password.
    • Keep the two shortcut checkboxes ticked.
  3. Click Create delegation.
  4. The Existing delegations tab lists everything and lets you remove any.

4. Student / standard user — run allowed programs

  1. Open Allowed Programs from the desktop (no UAC prompt).
  2. Double-click a program — it starts with administrator rights, on your own desktop.

The launcher is run-only: there is no uninstall, remove, or settings action.

5. Security notes

  • Delegating an application is like granting sudo on it — only delegate trusted, single-purpose apps.
  • Keep the app's .exe in a folder users cannot write to (e.g. Program Files), so it cannot be swapped for other code.
  • Every action is logged to C:\ProgramData\AppDelegation\audit.log.

6. Errors & causes

Error / symptomCauseFix
"side-by-side configuration is incorrect" — CreateProcess failed; code 14001 An embedded Win32 application manifest that this Windows could not turn into an activation context (or a damaged Windows component store / WinSxS). Use this installer — it ships without that manifest. If it persists, the PC's component store is corrupt: run sfc /scannow, then DISM /Online /Cleanup-Image /RestoreHealth, and restart.
Portable TaskDelegator.exe (net8) won't start, or missing vcruntime140.dll The self-contained .NET 8 build needs the Microsoft Visual C++ Redistributable, which is absent on clean machines. Use the installer or the net48 build (no VC++ needed), or install the VC++ 2015–2022 x64 Redistributable.
"This application requires .NET Framework 4.8" .NET Framework 4.8 is not installed (only happens on Windows 7). Install .NET Framework 4.8 — it is already built into Windows 10/11.
"Administrator rights are required", or the UAC prompt was cancelled The admin console needs elevation and the prompt was declined, or the account is not an administrator. Run Task Delegator (Administrator) and approve UAC with an administrator account.
Student double-clicks the shortcut but nothing opens The delegated app was moved/removed, there is no interactive session, or the task could not start. Check C:\ProgramData\AppDelegation\launcher.log; make sure the app still exists at its path and the user is signed in.
"No executable auto-detected for …" That application did not register a clean executable path. Click Browse… and pick the real .exe.
The shortcut landed on the Public desktop, not the user's That user has never signed in, so their profile/desktop does not exist yet. Have them sign in once, or leave it on the Public desktop (visible to all users).
Warning: "the executable is not under Program Files / Windows" The delegated .exe is in a folder the user can write to — they could replace it and run their own code elevated. Move the app to Program Files (admin-only) before delegating.

فارسی

۱. این برنامه چیست؟

Task Delegator به ادمین اجازه می‌دهد که اجازهٔ اجرای یک نرم‌افزار مشخص با دسترسی ادمین را به یک کاربر عادی (غیرادمین) بدهد — بدون دادن رمز ادمین. مناسب برای محیط آموزشگاه / آزمایشگاه: دانشجو می‌تواند نرم‌افزاری را که به دسترسی ادمین نیاز دارد اجرا کند، ولی نمی‌تواند آن را حذف (uninstall) یا تنظیمات را تغییر دهد.

۲. نصب

  1. TaskDelegatorSetup.exe را اجرا کنید و پنجرهٔ UAC را تأیید کنید.
  2. برنامه در Program Files نصب می‌شود و شورتکات‌ها را می‌سازد: Allowed Programs (برای همه) و Task Delegator (Administrator).
بدون پیش‌نیاز. نصب‌کننده از .NET Framework 4.8 که در ویندوز ۱۰/۱۱ توکار است استفاده می‌کند — چیز دیگری لازم نیست نصب شود.

۳. ادمین — ساخت یک تفویض (delegation)

  1. Task Delegator (Administrator) را باز کنید (یا برنامه را اجرا کرده و روی Administrator… بزنید) و UAC را تأیید کنید. همین «لاگین ادمین» است.
  2. در تب Create delegation:
    • نرم‌افزار نصب‌شده را از لیست انتخاب کنید (برای فیلتر تایپ کنید) یا با Browse… فایل .exe را انتخاب کنید.
    • کاربر ویندوز موردنظر را انتخاب کنید (برای کاربر Standard هم کار می‌کند).
    • Run as: حالت SYSTEM (بدون رمز) پیشنهاد می‌شود؛ یا Admin account را انتخاب و حساب ادمین + رمز را وارد کنید.
    • هر دو گزینهٔ شورتکات را فعال بگذارید.
  3. روی Create delegation کلیک کنید.
  4. در تب Existing delegations می‌توانید همه را ببینید و حذف کنید.

۴. دانشجو / کاربر عادی — اجرای برنامه‌های مجاز

  1. آیکن Allowed Programs را از روی دسکتاپ باز کنید (بدون UAC).
  2. روی یک برنامه دابل‌کلیک کنید — با دسترسی ادمین و روی دسکتاپ خودتان اجرا می‌شود.

این پنجره فقط-اجرا است: هیچ گزینهٔ حذف/uninstall یا تنظیماتی ندارد.

۵. نکات امنیتی

  • تفویض یک نرم‌افزار مثل دادن sudo روی آن است — فقط نرم‌افزارهای مورد اعتماد و تک‌منظوره را تفویض کنید.
  • فایل .exe برنامه را در مسیری بگذارید که کاربر اجازهٔ نوشتن ندارد (مثل Program Files)، تا با کد دیگری جایگزین نشود.
  • همهٔ عملیات در C:\ProgramData\AppDelegation\audit.log ثبت می‌شود.

۶. خطاها و علت‌ها

خطا / نشانهعلتراه‌حل
«side-by-side configuration is incorrect» — CreateProcess failed; code 14001 یک مانیفستِ Win32 داخل فایل exe که این ویندوز نتوانست از آن activation context بسازد (یا خرابیِ Component Store / WinSxS ویندوز). از همین نصب‌کننده استفاده کنید — بدون آن مانیفست ساخته شده. اگر باز هم بود، Component Store آن سیستم خراب است: sfc /scannow سپس DISM /Online /Cleanup-Image /RestoreHealth را اجرا و ری‌استارت کنید.
نسخهٔ پورتابل TaskDelegator.exe (net8) اجرا نمی‌شود، یا نبودِ vcruntime140.dll نسخهٔ self-contained دات‌نت ۸ به Microsoft Visual C++ Redistributable نیاز دارد که روی سیستم‌های تازه‌نصب نیست. از نصب‌کننده یا نسخهٔ net48 استفاده کنید (بدون نیاز به VC++)، یا VC++ 2015–2022 x64 را نصب کنید.
«This application requires .NET Framework 4.8» دات‌نت فریم‌ورک ۴.۸ نصب نیست (فقط روی ویندوز ۷ پیش می‌آید). .NET Framework 4.8 را نصب کنید — روی ویندوز ۱۰/۱۱ از قبل توکار است.
«Administrator rights are required» یا لغو شدن پنجرهٔ UAC کنسول ادمین به elevation نیاز دارد و پنجره رد شده، یا حساب ادمین نیست. Task Delegator (Administrator) را اجرا و UAC را با یک حساب ادمین تأیید کنید.
دانشجو روی شورتکات دابل‌کلیک می‌کند ولی چیزی باز نمی‌شود برنامهٔ تفویض‌شده جابه‌جا/حذف شده، سشن تعاملی وجود ندارد، یا تسک اجرا نشده است. فایل C:\ProgramData\AppDelegation\launcher.log را ببینید؛ مطمئن شوید برنامه در مسیرش هست و کاربر لاگین کرده است.
«No executable auto-detected for …» آن نرم‌افزار مسیرِ اجراییِ تمیزی ثبت نکرده است. روی Browse… بزنید و فایل .exe واقعی را انتخاب کنید.
شورتکات روی دسکتاپ Public ساخته شد، نه دسکتاپ کاربر آن کاربر هرگز لاگین نکرده، پس پروفایل/دسکتاپش هنوز ساخته نشده است. یک‌بار لاگین کند، یا روی دسکتاپ Public بماند (برای همه قابل‌دیدن است).
هشدار: «the executable is not under Program Files / Windows» فایل .exe تفویض‌شده در مسیری است که کاربر اجازهٔ نوشتن دارد — می‌تواند آن را با کد خودش جایگزین و با دسترسی ادمین اجرا کند. قبل از تفویض، برنامه را در Program Files (فقط-ادمین) قرار دهید.
